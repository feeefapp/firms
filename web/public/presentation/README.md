# Presentation asset sources

- `earth-blue-marble.jpg` and `earth-night.jpg`: NASA Earth imagery distributed in the three-globe
  example image set, pinned at https://unpkg.com/three-globe@2.31.0/example/img/ . These are the same
  Earth textures the Firms globe normally loads remotely.
- `sample-day.json`: 6,000 evenly sampled MODIS/VIIRS rows from the local NASA FIRMS snapshot
  `data/day/2026-11-01.js`. Five satellite definitions and the original measurement columns are retained.
  This is an archived demonstration sample, not a complete global count or a live monitoring feed.
- Space Grotesk and Manrope: self-hosted variable fonts from https://github.com/google/fonts .
  Their SIL Open Font License files are included in `fonts/`.

We acknowledge the use of data and/or imagery from NASA's Fire Information for Resource Management
System (FIRMS), part of NASA's Earth Science Data and Information System (ESDIS):
https://earthdata.nasa.gov/firms .
