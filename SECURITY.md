# Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability** (Security tab of
this repository) rather than a public issue. Include the affected endpoint or file, steps to
reproduce and the impact you expect. We aim to answer within a week.

Scope: the Rust server (`server/`: sign-in, OAuth for MCP, the API, the agent), the web app (`web/`)
and the Docker image. Rate-limit or quota exhaustion of NASA FIRMS through the public API is in scope.
